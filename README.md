# blind-pairs

Blind-pairs is a simple app for letter-pair word association practice and reinforcement.

## Data Source Acknowledgements

This project uses or references letter-pair data derived from these sources:

- [Speedsolving Wiki: List of letter pairs](https://www.speedsolving.com/wiki/index.php/List_of_letter_pairs)
- [Google Sheets letter-pair spreadsheet](https://docs.google.com/spreadsheets/d/1Fi4xgUz5b23UXMlHq7Tt5C8Ak8-U3XdbeQ9Anw68BQc/edit?gid=0#gid=0)
